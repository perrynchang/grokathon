# StudyPing: a 60-second demo

## Before recording

1. Start the app with `npm run dev` and open the local URL.
2. Open your profile/settings and choose **Reset demo**. The app returns to **Campus** with Perryn Chang’s sample courses selected and fresh session times.
3. Record at 1440 × 900 or a similar desktop size at 100% zoom. Start with Nora’s Organic Chemistry card visible under **Now**. If needed, choose Organic Chemistry in the course filter; **My courses** lets you change the selected courses.
4. Record while **Later today** has available times. The app uses New Haven time; near midnight, scheduling later today is intentionally unavailable.
5. Rehearse once, then reset again before the actual take. Keep **Additional options** collapsed for the main walkthrough.

This is a local interactive prototype. People, sessions, messages, and responses are demo data. No real invitations or notifications are sent.

## The take

If you want a brief chat moment, open **Chat** after joining Nora and send “Hi! I’ll meet you at the entrance.” Use a few seconds from the creation segment; the message remains local demo data.

## Optional longer walkthrough

- Open **My courses**, change a course, and show the feed updating. Explain that course interests are self-selected, not verified enrollment.
- Switch to **Quiet study** when hosting to show that students can work independently with company.
- Expand **Additional options** to change duration or group size, add a task/note, or select friends to invite. No direct invitations are selected by default.
- After creating a session with invited friends, use **Send demo reply** to simulate a friend’s **On the way** response. Name it as a demo response rather than a live notification.
- Show **Map**, **Friends**, or the **Focus** timer only if you have more time.
- **Find a study space** and **Reserve a room** link to Yale’s official tools. A StudyPing group spot includes the host in its capacity; it does not reserve physical seats or a room.

## Keep the take clear

- Let each action settle before clicking again, and pause on the confirmation details.
- Keep the cursor away from the card text while speaking.
- If a take goes wrong, use **Reset demo** before restarting.
- Describe the submission as an interactive prototype. Real Yale accounts, shared multi-user sessions, and notifications are planned for a later pilot.
